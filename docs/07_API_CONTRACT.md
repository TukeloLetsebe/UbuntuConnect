# API Contract

## Objective

Reverse engineer the REST API from the existing backend.

The implementation is the source of truth.

Do not make assumptions.

## Inspect

- Controllers
- Endpoints
- Swagger
- DTOs
- Validation
- Authorization
- Response Models

## Analyse

Discover:

- API modules
- Endpoint groups
- Request/Response models
- Authentication flow
- Authorization rules
- Validation rules
- HTTP status codes
- Endpoint dependencies

## Generate

- API Overview
- Module Breakdown
- Endpoint Catalogue
- Request/Response Catalogue
- Authentication Documentation
- Endpoint Dependency Map

## Rules

- Do not invent endpoints.
- Do not invent DTOs.
- Do not invent modules.
- Group endpoints according to the implemented architecture.
- If inconsistencies are found, report them.
