# UI_UX_SPECIFICATION.md

## Objective

Reverse engineer the UI/UX specification from the approved Figma design and compare it against the implemented frontend.

The Figma design is the source of truth for the user interface.

Do not make assumptions.

---

## Inspect

- Figma Project
- Pages
- Frames
- Components
- Design Tokens
- Typography
- Colours
- Icons
- Spacing
- Layouts
- Responsive Designs
- Navigation
- Interactions
- React Frontend

---

## Analyse

Discover:

- Design System
- Page Hierarchy
- Navigation Flow
- Component Library
- Design Tokens
- Responsive Behaviour
- User Flows
- Interaction Patterns
- Accessibility Considerations
- Consistency Between Design and Implementation

---

## Generate

### 1. UI Overview

Provide an overview of the design system.

---

### 3. Navigation Flow

---

### 4. Component Catalogue

Document reusable UI components.

---

### 5. Design System

Document colours, typography, spacing, icons and reusable styles.

---

### 6. Responsive Design

Document responsive layouts and breakpoints.

---

### 7. User Flows

Document the intended user journeys through the application.

---

### 8. UI Consistency Report

Compare the implemented frontend against the Figma design.

Identify:

- Missing Pages
- Missing Components
- Layout Differences
- Styling Differences
- Navigation Differences

---

### 9. UI Summary

Summarize the overall UI architecture.

## Rules

- Figma is the source of truth for UI.
- React implementation is the source of truth for implementation.
- Never invent pages.
- Never invent components.
- Report inconsistencies instead of assuming intent.
